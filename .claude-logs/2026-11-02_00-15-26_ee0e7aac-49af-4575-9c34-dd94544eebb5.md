Claude Account Switcher (version 0.3.6) is installed at `~/Applications/claude-account-switcher`. I didn't start it because the first start needs you to approve a keychain prompt. The project's own tests pass on this build.

**What I checked before installing:**
- **Your sign-ins:** they're only ever sent to `api.anthropic.com`, to read each account's usage. Nothing goes anywhere else.
- **Updates:** once a day it checks GitHub for a new version number. It only downloads one if you click update, and it checks the download against its published checksum.
- **What it changes:** the sign-in entries in Claude's `config.json` and its cookies file, plus the chat-list files it copies between accounts. It backs these up before every switch.

**How I installed it:** I built it from the source code instead of downloading the ready-made Mac file. That file isn't code-signed, and running it means turning off a macOS security check. Building it yourself avoids that and means you run exactly the code I read. Building needed Go, so I installed it with Homebrew (about 240 MB). You can remove it with `brew uninstall go` if you don't want it.

**Before you use it:**
- **Switching restarts the Claude desktop app, which is the app you're using right now.** Any session running here, this one included, stops mid-task. The switcher offers to resume chats that were mid-reply, but don't switch during long work.
- **It hasn't been tested on a Mac.** The author says the Mac version was only built automatically and never run on a real Mac, so expect rough edges.
- **It's unofficial,** not made or endorsed by Anthropic.

To start it:
```bash
~/Applications/claude-account-switcher &
```
Approve the "Claude Safe Storage" keychain prompt; that's the key Claude uses to encrypt its sign-in. Then turn on **Start at login** in its menu-bar menu. To add an account, sign in to your second account in Claude once, and from then on the switcher handles switching.
